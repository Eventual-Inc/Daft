Apache Arrow C Data Interface

This directory contains the Apache Arrow C Data Interface header (abi.h),
which is part of the Apache Arrow project.

Source: https://github.com/apache/arrow
File: cpp/src/arrow/c/abi.h
License: Apache License 2.0

Copyright: Apache Software Foundation

The Arrow C Data Interface is a standard ABI for exchanging Arrow data
between different systems without serialization. It defines C structs
(ArrowSchema and ArrowArray) that can be passed across language boundaries.
