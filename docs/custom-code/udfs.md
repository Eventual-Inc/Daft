# Legacy User-Defined Functions (UDFs)

!!! danger "Removed in 0.8.0"
    The legacy `@daft.udf` API was deprecated in Daft 0.7.0 and **removed in Daft 0.8.0**.

    Use [`@daft.func`](func.md) and [`@daft.cls`](cls.md) instead, and see the [migration guide](migration.md) for how to update your code.
